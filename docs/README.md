# Project Documentation

This folder contains the supporting documentation for the National Gas Network Operations Intelligence System.

It provides information about the data sources, dataset structure, field definitions, and operational KPIs used throughout the project.

## Documentation Files

### data_sources.md
Documents the National Gas Operational Data API, the endpoints used, data retrieval methods, available historical coverage, and source limitations.

### data_dictionary.md
Describes the fields in the collected dataset, including field names, data types, meanings, measurement units, and any relevant observations.

### kpi_definitions.md
Documents the operational KPIs used in the project, including their definitions, calculation methods, measurement units, and business relevance.

## Documentation Principles

- Use verified information from the actual API and collected dataset.
- Document data limitations and assumptions.
- Define KPIs clearly before using them in analysis.
- Keep documentation consistent with the Python, MySQL, and Power BI work.

# Raw Data

This folder stores the original operational data collected from the National Gas Operational Data API.

The retrieved API responses will be preserved in their original format before flattening, transformation, or cleaning.

**Purpose:**
- Store original API responses and collected operational datasets.
- Preserve source data for reference.
- Maintain data traceability.
- Provide a starting point for exploratory data analysis and data quality assessment.

Original data should remain unmodified.

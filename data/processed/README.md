# Processed Data

This folder stores the National Gas operational datasets after JSON flattening, data quality assessment, cleaning, and preparation using Python and Pandas.

The processed datasets will be structured for storage in MySQL and further gas transmission operations analysis.

**Purpose:**
- Store flattened API datasets.
- Store cleaned and prepared operational records.
- Maintain consistent data formats and field structures.
- Prepare validated datasets for MySQL storage and SQL analysis.
- Support gas flow, entry-point supply, and network performance analysis.

All transformations and cleaning decisions should be documented in the relevant Jupyter Notebooks.

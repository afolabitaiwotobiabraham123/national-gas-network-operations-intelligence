# Power BI Dashboard

This folder contains the Power BI dashboard and supporting screenshots developed for the National Gas Network Operations Intelligence System.

The dashboard will present key findings from the prepared operational dataset and SQL analysis in an interactive and business-focused format.

## Dashboard Objectives

- Monitor gas flow patterns across available transmission network sites.
- Compare gas flow contributions from different entry points.
- Track operational KPIs and flow variations over time.
- Identify unusual flow patterns and potential operational exceptions.
- Support operational performance monitoring and decision-making.

## Folder Structure

### dashboard/
Stores the Power BI dashboard file (`.pbix`).

### screenshots/
Stores screenshots of dashboard pages and important visualizations for project documentation.

## Tools
- Microsoft Power BI
- Power Query
- DAX

## Data Source
The dashboard will use prepared operational data and analysis results from the National Gas project.

**Note:** Dashboard metrics and visualizations will depend on the actual fields and operational information available in the collected dataset.
